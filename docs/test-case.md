# Описание тестового примера

Тестовый пример охватывает основные функции web-приложения.

## Исходные данные
- Сервер и клиент запущены.
- База заполнена командой `npm run db:seed`.
- Клиент: `client1@catering.local`, пароль `demo1234`.
- Менеджер: `manager@catering.local`, пароль `demo1234`.

## Последовательность
1. Выполнить вход под клиентом.
2. Перейти в меню.
3. Ввести часть названия блюда в поиск, применить категорию и сортировку.
4. Добавить несколько блюд в подбор меню.
5. Перейти к оформлению заявки.
6. Указать тип мероприятия, дату, количество гостей и адрес.
7. Проверить изменение расчетной стоимости при изменении количества гостей/позиций.
8. Отправить заявку.
9. Открыть «Мои заявки» и убедиться, что заявка отображается со статусом «Новая».
10. Выйти и войти под менеджером.
11. Открыть «Управление заявками», найти новую заявку и изменить статус на «Подтверждена».
12. На панели менеджера добавить тестовое блюдо, отредактировать его и удалить.
13. Открыть «Отчеты», указать период и скачать оба PDF-отчета.

## Ожидаемый результат
Все перечисленные действия выполняются без ошибок, данные сохраняются в PostgreSQL, роль клиента не получает доступ к страницам менеджера, а роль менеджера не использует клиентское оформление заявки.
