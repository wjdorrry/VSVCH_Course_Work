# Минимальный UI-kit

Визуальное направление основано на пользовательских референсах: светлый фон, фотографии/иллюстрации еды, спокойные темно-зеленые и шоколадные акценты.

## Цвета
- фон: `#F6F1E7`;
- светлая поверхность: `#FFFDF7`;
- основной зеленый: `#1F5A46`;
- темный зеленый: `#174434`;
- шоколадный: `#3D261F`;
- золотистый акцент: `#D4B85F`;
- границы: `#E5DDD0`;
- вторичный текст: `#7B756E`.

## Типографика
Без внешних шрифтов: системный sans-serif для интерфейса и Georgia для крупных заголовков. Это уменьшает число зависимостей и сохраняет единый стиль.

## Основные состояния
- кнопки: primary, outline, ghost, disabled, hover;
- ссылки навигации: normal, hover, active;
- поля: normal, focus;
- статусы заявки: новая, подтверждена, завершена, отменена;
- карточки: normal, hover;
- модальное окно и snackbar/toast.

## Адаптивные точки
- desktop: > 1020 px;
- tablet: 761–1020 px;
- mobile: 320–760 px.
