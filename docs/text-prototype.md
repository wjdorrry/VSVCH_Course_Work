# Текстовый прототип

## Главная (0.0)
1. Шапка: логотип, основная навигация, вход/выход, ссылка на подбор меню.
2. Первый экран: заголовок, краткое описание сервиса, кнопка «Собрать меню», иллюстрация кейтеринга.
3. Блок популярных блюд: 4 карточки.
4. Блок «Как это работает»: 3 шага.
5. Подвал: контакты и режим работы.

## Меню (1.0)
1. Заголовок и хлебные крошки.
2. Поиск по названию.
3. Сортировка.
4. Фильтр «только вегетарианские».
5. Фильтр по категориям.
6. Кнопка сброса локальных настроек фильтрации.
7. Сетка карточек блюд; для клиента — кнопка добавления в подбор.

## Оформление заявки (2.0)
1. Тип мероприятия.
2. Дата.
3. Количество гостей.
4. Адрес.
5. Комментарий.
6. Список выбранных блюд с изменением количества.
7. Расчет стоимости на гостя и общей ориентировочной стоимости.
8. Кнопка отправки заявки.

## Мои заявки (3.0)
1. Заголовок.
2. Фильтр по статусу.
3. Карточки заявок: номер, тип события, дата, количество гостей, стоимость, статус, адрес.

## Панель менеджера (4.0)
1. Три карточки статистики.
2. График распределения заявок по статусам.
3. Список популярных блюд.
4. Таблица последних заявок.
5. Таблица меню.
6. Добавление/редактирование блюда во всплывающем окне.
7. Удаление блюда.

## Управление заявками (4.1)
1. Фильтр по статусу.
2. Даты «с» и «по».
3. Таблица заявок.
4. Изменение статуса заявки.
5. Пагинация.

## Отчеты (4.2)
1. Выбор периода.
2. Карточка отчета по заявкам и кнопка PDF.
3. Карточка отчета по популярности блюд и кнопка PDF.
4. Краткий график популярности блюд.

## Авторизация (5.0)
1. Email.
2. Пароль.
3. Кнопка входа.
4. Ссылка на регистрацию.
5. Данные демонстрационного аккаунта менеджера.

## Регистрация (6.0)
1. Имя.
2. Email.
3. Телефон.
4. Пароль.
5. Кнопка регистрации.
6. Ссылка на авторизацию.
