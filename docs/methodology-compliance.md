# Соответствие минимальным требованиям методички

Тема: **«Разработка онлайн-платформы для управления системой кейтеринга»**.
Проект сознательно не усложнён сверх минимальных требований.

## Роли
Ровно две роли с различающимися функциями:
- `CLIENT` — подбор меню, создание заявки, просмотр своих заявок;
- `MANAGER` — обработка заявок, управление меню, аналитика и отчёты.

## Страницы
Страницы авторизации и регистрации существуют отдельно. Кроме них реализовано не менее 7 страниц:
1. Главная `/`;
2. Меню `/menu`;
3. Оформление заявки `/request`;
4. Мои заявки `/my-requests`;
5. Панель менеджера `/manager`;
6. Управление заявками `/manager/requests`;
7. Отчёты `/reports`.

Дополнительно есть техническая страница 404.

## Функции приложения
Авторизация и регистрация не включены в список ниже.
1. Поиск блюд по названию.
2. Фильтрация блюд по категории.
3. Фильтрация вегетарианских блюд.
4. Сортировка блюд по названию и цене.
5. Сохранение фильтров меню в localStorage.
6. Сброс пользовательских настроек localStorage.
7. Добавление блюда в подбор меню.
8. Изменение количества выбранной позиции.
9. Расчёт ориентировочной стоимости на гостя.
10. Расчёт общей стоимости с учётом количества гостей.
11. Формирование и отправка заявки на мероприятие.
12. Просмотр клиентом собственных заявок.
13. Фильтрация клиентских заявок по статусу.
14. Просмотр менеджером всех заявок.
15. Фильтрация заявок менеджером по статусу и диапазону дат.
16. Изменение статуса заявки менеджером.
17. Добавление, изменение и удаление блюд менеджером.
18. Отображение статистики заявок по статусам.
19. Отображение популярных блюд.
20. Формирование PDF-отчёта по заявкам за период.
21. Формирование PDF-отчёта по популярности блюд.

## Отчёты
- `catering-requests-report.pdf` — заявки за выбранный период;
- `popular-dishes-report.pdf` — популярность блюд за выбранный период.

## Интерфейсные компоненты
В проекте физически реализовано более 20 различных компонентов: AppLayout, Header, Footer, ProtectedRoute, Button, FormField, Input, Select, TextArea, SearchInput, CategoryPill, DishImage, DishCard, StatusBadge, QuantityStepper, StatsCard, BarChart, EmptyState, LoadingSpinner, Toast, Modal, Breadcrumbs, PageHeader, DataTable, Pagination, RequestCard, SectionTitle.

## Адаптивность
CSS содержит отдельные адаптивные состояния для desktop, tablet и mobile. Минимальная поддерживаемая ширина — 320 px. Горизонтальная прокрутка допускается только внутри табличного контейнера, а не у всей страницы.

## localStorage
Сохраняются:
- JWT и данные текущего пользователя;
- выбранные блюда и их количества;
- фильтры и сортировка каталога.

На странице меню есть кнопка сброса настроек фильтров.

## База данных
PostgreSQL + Sequelize. Ровно 8 предметно связанных таблиц. `npm run db:seed` создаёт больше 200 записей для тестирования.

## API
RESTful API с CRUD-операциями для блюд и базовыми операциями над заявками.

## Технологии
- клиент: React, React Router, Vite, HTML5, CSS, JavaScript;
- сервер: Node.js, Express;
- слой данных: Sequelize;
- СУБД: PostgreSQL;
- авторизация: JWT;
- отчёты: PDFKit.
