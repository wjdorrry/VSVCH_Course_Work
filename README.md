# Gather — онлайн-платформа для управления системой кейтеринга

Учебный web-проект по теме **«Разработка онлайн-платформы для управления системой кейтеринга»**. Реализация сделана намеренно компактной: только то, что требуется для выполнения минимальных требований курсовой.

## Быстрый запуск

### Вариант 1 — Windows + Docker

1. Установить Node.js 20+ и Docker Desktop.
2. Распаковать проект.
3. Запустить `start-project.bat`.
4. Открыть `http://localhost:5173`.

### Вариант 2 — вручную

```bash
docker compose up -d db
npm install
npm run db:seed
npm run dev
```

Клиент: `http://localhost:5173`  
API: `http://localhost:4000/api`

## Демонстрационные аккаунты

- клиент: `client1@catering.local` / `demo1234`;
- менеджер: `manager@catering.local` / `demo1234`.

## Роли

- **CLIENT** — каталог, подбор меню, оформление заявки, просмотр собственных заявок;
- **MANAGER** — обработка заявок, изменение статусов, управление меню, аналитика и два PDF-отчёта.

## Технологии

- React 18 + React Router + Vite;
- Node.js + Express;
- PostgreSQL;
- Sequelize ORM;
- JWT + bcryptjs;
- PDFKit.

## Структура

- `client/` — клиентская часть;
- `server/` — REST API;
- `database/` — SQL-схема/демоданные;
- `docs/` — структура приложения, текстовый прототип, тестовый пример, UI-kit и проверка соответствия методичке.

## Зависимости

Все прямые зависимости и версии зафиксированы в `package.json` файлов корня, `client` и `server`, а также перечислены в `DEPENDENCIES.txt`.

`node_modules` не хранится в ZIP: это генерируемая папка. После `npm install` npm создаёт её автоматически. Такой способ позволяет передавать проект без огромного дублирования библиотек.
